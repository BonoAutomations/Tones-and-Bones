# Tones-and-Bones
Luxury Sales and Marketing Automation V1

## Local page: `about-bono-g-youtube_3.html`
This repository includes a fully functional standalone YouTube hub page for Bono G.

### Features
- Responsive “About Bono G” layout with dark/light mode.
- Featured embedded videos with add/remove controls.
- Robust YouTube URL parsing (`watch`, `youtu.be`, `shorts`, `embed`, and direct IDs).
- Quick external links (YouTube Home, Search, Subscriptions, Trending, Studio).
- Open-all-links action for current featured videos.
- JSON export/import tools for backup/restore.
- Data persistence with `localStorage`.

### Run locally
Open the file directly, or run a local server:

```bash
python3 -m http.server 4173
```

Then visit:

- `http://localhost:4173/about-bono-g-youtube_3.html`
