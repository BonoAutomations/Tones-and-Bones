# Tones-and-Bones

Luxury Sales and Marketing Automation V1

## Dashboard Project

This repository now contains a static **Command Center / Terminal Hub** dashboard prototype built as a single HTML file.

### Files

- `index.html` — full dashboard markup, Tailwind CDN setup, custom theme config, and small inline visual behaviors

### Design highlights

- three-column terminal-inspired operations layout
- left navigation with global metrics
- center live event stream with hover tooltip and shimmer loading placeholders
- right-side system health status panel
- bottom command input bar for the command-center interaction model

### Run locally

Open `index.html` directly in a browser, or serve the project locally with:

```bash
python3 -m http.server 8000
```
