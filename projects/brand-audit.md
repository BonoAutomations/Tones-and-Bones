# Brand Audit

Run this project quarterly, or immediately when: you've been attracting the wrong clients, your close rate has dropped below 50%, or something feels off about how the brand is being perceived.

## Audit Areas

### 1. Positioning Check
- [ ] Run `/luxury-positioning` — does the current position still hold?
- [ ] Is the singular promise still true and differentiated?
- [ ] Has a competitor moved into your territory?
- [ ] Would your three best clients describe your value without mentioning price?

### 2. Brand Voice Check
- [ ] Review the last 10 pieces of client-facing communication (emails, proposals, social)
- [ ] Do they all sound like the same brand?
- [ ] Is there any urgency language, discounting, or over-explanation?
- [ ] Does the tone reflect: calm confidence, invitation, curation?

### 3. Brand Story Check
- [ ] Run `/brand-story` — is the origin scene still resonant?
- [ ] Has the philosophy deepened or shifted?
- [ ] Is the client transformation statement still accurate?
- [ ] When did you last update your About page?

### 4. Ideal Client Drift Check
- [ ] Run `/ideal-client-profile` — have the archetypes shifted?
- [ ] Who were the last 5 clients? Were they all the right fit?
- [ ] Has a new trigger event emerged that you should be speaking to?
- [ ] Are you still targeting the right referral sources?

### 5. Touchpoint Audit
- [ ] Website: does it reflect current positioning?
- [ ] Social: consistent with brand voice?
- [ ] Proposals: still the brand standard you'd be proud of?
- [ ] Email signatures, booking pages, intake forms: all on-brand?

## Deliverables

1. A one-paragraph summary of positioning health
2. A list of 3 touchpoints to update before next month
3. One brand promise or story element to sharpen
4. Updated ideal client archetype if drift detected
