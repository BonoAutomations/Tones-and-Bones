# Pricing Overhaul

Run this project when: you're raising rates, restructuring your offer, launching a new service tier, or if close rate exceeds 80% (a signal that demand exceeds supply and prices should rise).

## Phase 1: Diagnosis

- [ ] Run `/pricing-strategy` for full framework
- [ ] What is the current pricing model? (hourly / project / retainer / package)
- [ ] What is the average contract value right now?
- [ ] What is the close rate? (above 80% = underprice signal)
- [ ] Are there any active discounting patterns? Who, when, why?
- [ ] Are clients ever surprised by the price (too high or too low)?

## Phase 2: Outcome Value Mapping

For each core service, answer:
- [ ] What specific transformation does the client experience?
- [ ] What is that transformation worth to their life, career, or business?
- [ ] What do the top 10% of competitors in this category charge?
- [ ] What is the appropriate price at 20-40% below outcome value?

## Phase 3: Package Architecture

Design three tiers. Work backwards from the middle tier (your target).

| Tier | Name | Scope | Investment | Purpose |
|---|---|---|---|---|
| Entry | ___ | ___ | $___ | Accessible starting point, not a discount |
| Core | ___ | ___ | $___ | Where most clients land — your real target |
| Legacy | ___ | ___ | $___ | Anchors value, makes Core feel smart |

- [ ] Name each tier in your brand language (not "Basic / Standard / Premium")
- [ ] Define what is included and explicitly what is not
- [ ] Set the price for each tier
- [ ] Identify the signature outcome for each tier

## Phase 4: Price Defense Language

Prepare scripts for three common objections:

- [ ] "That's more than I expected." → Response: ___
- [ ] "Can you do it for less?" → Response: ___
- [ ] "What's your best rate?" → Response: ___

All responses should: acknowledge, re-anchor to value, offer scope adjustment (not discount).

## Phase 5: Rollout

- [ ] Determine effective date for new pricing
- [ ] Notify existing retainer clients with 30 days advance notice
- [ ] Update proposal templates
- [ ] Update any published pricing pages
- [ ] Brief any team members who discuss pricing with clients

## Deliverables

1. Three-tier package structure (named, scoped, priced)
2. Price defense script for three common scenarios
3. Rollout plan and effective date
4. One thing that will no longer be offered at a discount or for free
