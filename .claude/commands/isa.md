# /isa — Create an Ideal State Artifact

Create an ISA (Ideal State Artifact) for the project, campaign, or feature described in $ARGUMENTS.

An ISA is a hard-to-vary description of what "done" looks like. It drives the build and verifies the outcome. Work through all 12 sections.

---

## ISA: [Title from $ARGUMENTS]

**Date:** [today]  
**Version:** 1.0  
**Owner:** [infer from context or ask]  
**Effort Tier:** [Minimal / Standard / Comprehensive]

---

### 1. Problem
What is wrong, missing, or suboptimal right now? Be specific. No vague statements.

### 2. Vision
Describe the ideal end state in vivid, concrete terms. A reader should be able to picture it.

### 3. Out of Scope
What are we explicitly NOT doing in this effort? Set clear boundaries.

### 4. Principles
What values guide trade-off decisions? (e.g., "exclusivity over reach", "story before spec")

### 5. Constraints
Hard limits: budget, timeline, brand guidelines, tech stack, regulatory.

### 6. Goal
One sentence. Complete this: "This effort succeeds when ___."

### 7. Criteria
Measurable conditions that confirm the Goal is met. Each criterion must be testable.

- Criterion 1: [measurable]
- Criterion 2: [measurable]
- Criterion 3: [measurable]

### 8. Test Strategy
How will we verify each criterion is satisfied? Who tests? When?

### 9. Features
What capabilities, deliverables, or components are required?

- Feature 1
- Feature 2
- Feature 3

### 10. Decisions
Key choices already made and the reasoning behind them.

| Decision | Choice | Rationale |
|----------|--------|-----------|
| | | |

### 11. Changelog
How has this ISA evolved?

| Version | Change | Date |
|---------|--------|------|
| 1.0 | Initial creation | [today] |

### 12. Verification
Final sign-off checklist before marking this effort complete.

- [ ] All Criteria from Section 7 are demonstrably met
- [ ] Stakeholders have reviewed and approved
- [ ] Brand voice and aesthetic standards upheld
- [ ] No out-of-scope items crept in
- [ ] LEARNING.md updated with key insights
